# 임원 AI 사용 현황 설문

회의 중 QR로 참여하는 8문항 설문과 실시간 통계 화면.

| 경로 | 용도 |
|---|---|
| `/` | 설문 (모바일 최적화, QR 대상) |
| `/stats.html` | 실시간 결과 — 4초마다 자동 갱신, 빔 프로젝터용 |
| `/qr.html` | QR 코드 화면 (배포 후 자동으로 자기 주소를 인코딩) |

문항은 `api/_questions.js` 한 곳에만 정의되어 있고 설문·통계 화면이 이를 공유한다.
문항을 고치려면 그 파일만 수정하면 된다.

## 배포

### 1. GitHub

```bash
git remote add origin https://github.com/<계정>/byucksan-ai-survey.git
git push -u origin main
```

### 2. Vercel

1. vercel.com → **Add New → Project** → 위 저장소 선택
2. 프레임워크는 **Other**, 빌드 설정은 그대로 두고 Deploy
   (`public/`가 정적 파일, `api/`가 서버리스 함수로 자동 인식된다)

### 3. 저장소 연결 — **이 단계를 건너뛰면 응답이 저장되지 않는다**

서버리스 함수는 상태를 유지하지 못하므로 외부 저장소가 필요하다.
**구글 시트**를 쓴다 — 설치 방법은 [`apps-script/README.md`](apps-script/README.md) 참고.

요약하면 스프레드시트에 `apps-script/Code.gs` 를 붙여넣고 웹 앱으로 배포한 뒤,
Vercel 환경변수에 `SHEET_API_URL` 과 `SHEET_TOKEN` 을 등록하고 재배포하면 된다.

응답이 시트에 한 줄씩 쌓이므로 회의 후 정렬·필터·피벗으로 바로 분석할 수 있다.

> Redis(Upstash/Vercel KV)도 쓸 수 있다. `KV_REST_API_URL` 과 `KV_REST_API_TOKEN` 이 있으면 인식한다.
> 저장소가 없으면 `/stats.html` 상단에 경고 배너가 뜬다. **회의 전에 반드시 확인할 것.**

## 회의 진행

1. 빔에 `/qr.html`을 띄운다
2. 참석자가 QR을 스캔해 응답한다 (약 2분)
3. `/stats.html`로 전환하면 결과가 4초마다 갱신된다
4. 화면을 보면서 토론을 시작한다

## 문항 구성

| # | 문항 | 형식 |
|---|---|---|
| 1 | 현재 쓰고 계신 AI 서비스 | 복수 |
| 2 | 유료 구독 여부 | 단일 |
| 3 | 사용 빈도 | 단일 |
| 4 | 주로 쓰는 용도 | 복수(최대 3) |
| 5 | AI 에이전트를 써 보셨습니까 | 단일 |
| 6 | 어디까지 허용하시겠습니까 | 단일 |
| 7 | 업무 자료를 외부 AI에 입력한 적 | 단일 |
| 8 | 회사가 유료 계정을 제공한다면 | 단일 |
| — | 한마디 | 선택 주관식 |

### 설계 의도

- **2번(유료 여부)** — 회사 비용과 개인 비용을 나눈 것은, 이미 개인 돈으로 쓰는 임원 비율이
  회사 지원의 정당성 근거가 되기 때문이다.
- **5번(에이전트)** — 문항에 설명을 붙였다. 용어만 던지면 인지도 응답이 부풀려진다.
- **6번(허용 범위)** — 「AI를 얼마나 믿나」는 답이 안 나오지만 「어디까지 맡기겠나」는 답이 나오고,
  그대로 권한 설계 기준이 된다.
- **7번(자료 입력)** — 익명 집계임을 문항에 명시했다. 책임 추궁으로 읽히면 전부 「없다」가 나온다.
- 소속·성명을 묻지 않는다. 임원 모수가 작아 특정될 수 있어 교차분석보다 솔직한 응답을 택했다.

### 집계 후 먼저 볼 것

1. 개인 비용으로 유료 구독 중인 비율 → 회사 지원의 정당성
2. 7번에서 「있다」 비율 → 보안 가이드라인의 시급성
3. 1번에서 「사용하지 않음」 비율 → 교육이 먼저인지 정책이 먼저인지

## 로컬 확인

```bash
npx vercel dev
```

저장소 환경변수가 없으면 메모리에 저장되며 프로세스가 끝나면 사라진다.

## 데이터

- Redis 리스트 `survey:v1:responses`에 응답 JSON이 순서대로 쌓인다
- 응답에는 시각과 선택지만 저장되며 IP·이름·계정 정보는 저장하지 않는다
- 정의되지 않은 값은 서버에서 걸러지고, 복수응답 상한도 서버에서 다시 적용된다
