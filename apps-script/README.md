# 구글 시트를 저장소로 쓰기

응답이 시트에 한 줄씩 쌓이므로, 회의가 끝나면 그대로 정렬·필터·피벗으로 분석할 수 있다.
서비스 계정이나 OAuth 설정이 필요 없고 **Apps Script 웹앱 URL 하나**만 있으면 된다.

## 설치 (약 5분)

### 1. 스프레드시트 만들기

sheets.new 로 새 시트를 만든다. 이름은 자유 (예: `임원 AI 설문 응답`).

### 2. 스크립트 붙여넣기

메뉴 **확장 프로그램 → Apps Script** → 기본 코드를 지우고 `Code.gs` 내용을 붙여넣는다.

**상단의 `SECRET` 값을 반드시 바꾼다.**

```javascript
const SECRET = 'CHANGE_ME_1234';   // ← 아무도 모를 문자열로 변경
```

### 3. 웹 앱으로 배포

**배포 → 새 배포 → 유형 선택(톱니) → 웹 앱**

| 항목 | 값 |
|---|---|
| 설명 | 아무거나 |
| 다음 사용자로 실행 | **나** |
| 액세스 권한이 있는 사용자 | **모든 사용자** |

→ **배포** → 권한 승인 (본인 계정 선택 → 「고급」 → 「안전하지 않음으로 이동」 → 허용)

승인 화면의 경고는 **본인이 만든 스크립트라서 뜨는 것**이다. 시트 접근 권한만 요구한다.

배포가 끝나면 이런 URL이 나온다. **이것을 복사한다.**

```
https://script.google.com/macros/s/AKfycb...../exec
```

### 4. Vercel 환경변수 등록

프로젝트 → **Settings → Environment Variables**

| 이름 | 값 |
|---|---|
| `SHEET_API_URL` | 3단계에서 복사한 `/exec` URL |
| `SHEET_TOKEN` | 2단계에서 정한 `SECRET` 과 **같은 값** |

등록 후 **재배포**해야 적용된다.

## 확인

`/stats.html` 상단에 경고 배너가 사라지면 연결된 것이다.
설문을 한 번 제출해 보고 시트에 행이 늘어나는지 확인하면 확실하다.

## 시트 구조

응답 1건이 한 행으로 쌓인다. **JSON 한 줄이므로 문항이 바뀌어도 시트를 고칠 필요가 없다.**

| 시각 | json |
|---|---|
| 2026-09-18 09:12 | `{"at":"2026-09-18T00:12:03.120Z","answers":{"tools":["ChatGPT","Claude"],"paid":"개인 비용으로 유료 사용",...},"comment":"..."}` |

### 표로 펼쳐서 분석하기

JSON 그대로는 정렬·피벗이 어려우므로 변환 기능을 넣어 두었다.

시트 상단 메뉴 **「설문」 → 「응답을 표로 펼치기」**

`flat` 시트가 새로 만들어지고 문항별 열로 펼쳐진다. 원본 `responses` 시트는 건드리지 않는다.
복수 응답은 `, ` 로 이어 붙는다. 다시 누르면 최신 상태로 새로 그린다.

> 메뉴가 안 보이면 시트를 새로고침한다. (`onOpen` 은 문서를 열 때 등록된다)

## 주의

- **`SECRET` 을 바꾸지 않으면** URL을 아는 사람이 응답을 넣거나 읽을 수 있다.
- 스크립트를 수정한 뒤에는 **「배포 관리 → 편집 → 버전: 새 버전」** 으로 다시 배포해야 반영된다.
  새 배포를 만들면 URL이 바뀌므로, 기존 배포를 수정하는 편이 낫다.
- 시트에는 선택지와 시각만 저장된다. IP·이름·계정 정보는 저장하지 않는다.
- Apps Script 는 응답 1건당 0.3~1초 정도 걸린다. 회의 규모(수십 명)에서는 문제없다.
